# 📚 College Projects Archive

This repository is a personal archive of various small projects and case studies I completed during my college years. It includes simple web development work and programming projects in C and COBOL. Each project reflects different subjects and skills I explored as a student.

---

## 📁 Contents

### 1. 🌐 PUPQC Website (HTML/CSS)
A basic static website created using **HTML** and **CSS** to represent **Polytechnic University of the Philippines – Quezon City (PUPQC)**.  
Features:
- School-themed design
- Informative sections (About, Courses, Contact)
- Pure front-end project (no backend or JavaScript)

> 📂 Folder: `pupqc-website/`

### 2. 🏦 C Banking System (File Handling)
A console-based banking application written in **C**, using **file handling** to store and retrieve customer data.  
Features:
- Create, update, and delete accounts
- Deposit and withdraw functionality
- File-based persistence

> 📂 Folder: `c-banking-project/`

### 3. 💻 COBOL Banking Case Study
A simple **banking case study** written in **COBOL**, typically part of a legacy systems programming subject.  
Features:

- Simulates core banking operations

> 📂 Folder: `cobol-banking-case-study/`
